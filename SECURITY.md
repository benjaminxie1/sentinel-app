| 0.1.x   | :white_check_mark: |

---

## Reporting a Vulnerability

The Sentinel team takes software security in safety-adjacent environments seriously. If you discover a potential vulnerability or security flaw, please report it privately:

1. **Do not disclose publicly** via GitHub Issues, Discussions, or pull requests.
2. **Email maintainers**: Send details to `bxie2015@gmail.com` with the subject line `[SECURITY] Sentinel Vulnerability Report`.
3. **Include details**:
   - Detailed description of the vulnerability.
   - Proof-of-concept steps or payload to reproduce.
   - Affected component (e.g. RTSP parser, local REST/WebSocket server, authentication).

### Response Timeline
- **Acknowledgement**: Within 24 hours.
- **Triage & Assessment**: Within 48 hours.
- **Patch Release & Advisory**: Within 7 business days.

Thank you for responsibly disclosing security vulnerabilities to keep open-source systems safe.
